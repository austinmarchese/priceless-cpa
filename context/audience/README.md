# Audience

Deep profiles of who you're creating content for.

## What Goes Here

- Industry profiles (dentists, lawyers, e-commerce, etc.)
- Client personas within industries
- Pain points and language they use
- What triggers them to seek help
- Objections and how to handle them

## How to Add Profiles

Create industry folders: `dentists/`, `lawyers/`, `ecommerce/`

Inside each, add:
- `profile.md` — The core audience profile
- `pain-points.md` — Detailed pain points and language
- `objections.md` — Common objections and responses

## How AI Uses This

When creating content for a specific industry, AI references these profiles to speak directly to their pain in their language—not generic accounting copy.

## Tip

The `/industry-page` skill asks questions that surface this information. After running it, save the insights here for future content.
