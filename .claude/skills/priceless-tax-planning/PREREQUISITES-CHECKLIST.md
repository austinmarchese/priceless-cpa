# Prerequisites Checklist

> **Note:** This file previously shipped with the wrong contents (a duplicate of the Mississippi state file). Reconstructed to match the workflow in `SKILL.md`. The real Mississippi state file lives at `states/MISSISSIPPI.md`.

Confirm every item below **before** starting a quarterly engagement. Engagements that begin with missing prerequisites produce low-quality output and force assumptions. If an item cannot be confirmed, either obtain it or explicitly log it as an open assumption in the memo — never silently default.

## 1. Engagement and compliance gates

- [ ] **Engagement tier** identified (Foundational / Comprehensive / Full Wealth) — drives which memo sections fire
- [ ] **Current quarter** confirmed (Q1 / Q2 / Q3 / Q4) — drives timing windows and the cadence deliverable
- [ ] **Signed engagement letter** in place, including AI-use disclosure
- [ ] **Licensure check** — Priceless is registered/authorized to practice in the client's state(s)
- [ ] **Attest-client status** checked — if an attest client, no commission-based / Path B product recommendations (see `shared/REFERRAL-DISCLOSURE-FRAMEWORK.md`)
- [ ] **§7216 consent** status (if affiliate information sharing is contemplated)
- [ ] **No active IRS / state examination** that changes posture (if one exists, escalate to partner before proceeding)

## 2. Documents in hand (redacted per `shared/REDACTION-PROTOCOL.md`)

- [ ] **Prior-year returns** — personal 1040 (all schedules + K-1s) and every business return the client has a material interest in (1120-S / 1065 / 1120), plus state returns
- [ ] **Two-years-prior return** (optional but valuable — catches trend issues and verifies carryforward consistency)
- [ ] **Current-year financials** — YTD P&L, Balance Sheet, and **General Ledger** (the GL is required to verify payroll and catch miscoded items)
- [ ] **Payroll detail** — enough to separate **officer vs. staff** wages and confirm what has run YTD
- [ ] **Any existing-strategy evidence** — retirement plan statements, PTET filings, cost-seg studies, prior elections

## 3. Client profile completeness (`shared/CLIENT-PROFILE-TEMPLATE.md`)

- [ ] All 12 sections populated (or gaps flagged)
- [ ] Entity structure, ownership %, and industry confirmed
- [ ] Carryforwards and basis position captured from the prior-year return
- [ ] Existing strategies and financial products recorded (so we don't recommend what's already in place)
- [ ] Known current-year events listed

## 4. Intake gate items (see `SKILL.md` Step 3.5 — confirm or ask)

These are the facts most often missing that force assumptions. Confirm from documents or ask the analyst:

- [ ] **Owner age(s)** (retirement-plan sizing)
- [ ] **Officer vs. staff payroll split** and **YTD officer comp / withholding / estimates actually run** (often $0 early in the year)
- [ ] **Existing retirement plan?**
- [ ] **Source of capital gains** (portfolio → NIIT vs. active-business → possibly excluded)
- [ ] **New location / major asset use and in-service date** (cost-seg / bonus timing)
- [ ] **Family facts** (children for income-shifting; employed spouse)
- [ ] **State apportionment + existing elections** pulled from the prior-year return (carry forward unless a known event changes them)

## 5. Ready-to-proceed

- [ ] All Section 1 gates clear (or partner has cleared exceptions)
- [ ] Enough of Sections 2–4 in hand to build a defensible baseline
- [ ] Remaining gaps written into the engagement's open-questions list

When Sections 1–4 are confirmed, proceed to `SKILL.md` Step 2.
