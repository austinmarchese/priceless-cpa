Video ideas for Priceless CPA YouTube content are tracked in the Notion database "[Priceless] Social Media" (collection://3040df1f-244e-803a-b840-000b46f9686c). Each video has a status (Content Ideas, In Production, etc.), video type (YT Video), title, and thumbnail concepts. The board lives under: The Incubator > Priceless Company Operating System > Priceless CPA Media Team.

When the user shares Notion links for new video ideas, pull the title, status, thumbnail notes, and any design feedback, then add them to `content/youtube/ideas/` in the local OS.
