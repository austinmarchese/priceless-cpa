# Tax Knowledge Base

Reference files for tax topics, strategies, and code sections used in video scripts.

## How to Use
When writing scripts with `/priceless-youtube-script-writer`, this folder is scanned for relevant tax topic deep dives.

## Adding Knowledge
Create a new file for each major tax topic:
- Name: `[topic-slug].md` (e.g., `cost-segregation.md`, `qbi-deduction.md`)
- Include: IRC sections, key tests, common misconceptions, client-ready examples
- Reference raw research: "See [[raw/research/[topic]]] for source material"
