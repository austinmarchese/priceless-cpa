# Project Recipes

Quick reference for which folders to load based on what you're working on.

---

## YouTube Script

**Use when:** Writing a full YouTube video script (10-20 min)

**Wiki folders:**
```
wiki/youtube-scripts/       # Script structure, intro formulas, body techniques
wiki/anthony/               # Voice patterns, best work, lived experiences
wiki/audience/              # Serial entrepreneur persona
wiki/consultants/           # Expert frameworks
```

**Raw folders:**
```
raw/outliers/               # Proven patterns and titles
projects/videos/            # Active video projects
```

**Key consultants:** karlton-dennis (hooks, authority positioning), jasmine-dilucci (tax authority framing)

---

## Video Idea / Title Research

**Use when:** Generating or scoring video title options

**Wiki folders:**
```
wiki/audience/              # Who will click, what pain points to target
```

**Raw folders:**
```
raw/outliers/               # 19 analyzed videos, 6 patterns, adapted titles
```
